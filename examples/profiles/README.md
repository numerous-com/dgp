# Optional profile fixtures

These are synthetic static protocol records, not a live server trace or calculated farm results. IDs cross-reference the Farm Energy frame where relevant. The handoff is a separate illustrative continuation. Reserved `.invalid` domains are intentionally nonfunctional.

`fixture-index.json` maps files to definitions in `schemas/dgp.profiles.schema.json`. The core schema is embedded unchanged for local validation. Run `python tools/validate_bundle.py` from the repository root.
